# Git Hands-on Exercises

## Overview
This folder contains the Git hands-on exercises completed as part of the Cognizant Deep Skilling Java FSE program. The exercises cover the fundamental Git operations required for version control and collaboration using GitLab.

## Exercises Completed

### Exercise 1 – Git Repository Setup
- Configured Git username and email
- Created a local Git repository
- Added files to staging
- Performed the initial commit
- Connected the repository to GitLab
- Pushed the project to the remote repository

### Exercise 2 – Git Ignore
- Created a `.gitignore` file
- Ignored log files and folders
- Verified ignored files using `git status`

### Exercise 3 – Branching and Merging
- Created a new branch
- Added and committed changes
- Compared branches
- Merged the branch into `master`
- Deleted the merged branch

### Exercise 4 – Merge Conflict Resolution
- Created conflicting changes in different branches
- Resolved merge conflicts manually
- Updated `.gitignore`
- Committed the resolved changes

### Exercise 5 – Repository Cleanup and Remote Synchronization
- Verified repository status
- Listed available branches
- Pulled the latest changes from the remote repository
- Pushed local changes to GitLab
- Verified the updated repository on GitLab

## Git Concepts Covered
- Git configuration
- Repository initialization
- Staging and committing
- Remote repositories
- GitLab integration
- `.gitignore`
- Branching
- Merging
- Merge conflict resolution
- Pull and push operations
- Repository synchronization

## Outcome
Successfully completed all five Git hands-on exercises and gained practical experience with Git version control and GitLab repository management.
